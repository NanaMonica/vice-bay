Vice Bay is a top-down open-world crime game: drive around a fictional city, steal cars, outrun the police as your wanted level rises, and run 3 missions for cash.

## Play

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Keyboard: WASD to walk/drive, E to steal a car, F to fight, P to pause, M to mute, C to save.

Built for make.fun's ["Make GTA 6" bounty](https://make.fun/bounty/gta6-01) (gta6-01). All art, sound, city, characters and story are original — no assets from Rockstar Games.
